## Download

Always get HexaDesktop from the [**Releases page**](https://github.com/gethexa/HexaDesktop-Releases/releases/latest). Pick the file that matches your operating system:

| Platform | File | Notes |
| --- | --- | --- |
| **Windows** 10/11 (64-bit) | `HexaDesktop-Setup-<version>-x64.exe` | Recommended installer |
| **Windows** (portable) | `HexaDesktop-<version>-win-x64.zip` | No installation required |
| **macOS** 12+ (Apple Silicon) | `HexaDesktop-<version>-arm64.dmg` | M1 / M2 / M3 / M4 |
| **macOS** 12+ (Intel) | `HexaDesktop-<version>-x64.dmg` | |
| **Linux** (x64) | `HexaDesktop-<version>-x86_64.AppImage` | Most distributions |
| **Linux** (Debian/Ubuntu) | `hexadesktop_<version>_amd64.deb` | |

> [!TIP]
> Not sure which one you need? On Windows choose the `.exe` installer. On a Mac, click  → *About This Mac*: if it says **Apple M…**, choose `arm64`, otherwise choose `x64`.

Every release also includes a `SHA256SUMS.txt` file so you can [verify your download](docs/installation.md#verifying-your-download).

## Quick start

1. Download the installer for your platform from the [latest release](https://github.com/gethexa/HexaDesktop-Releases/releases/latest).
2. Install it — see the [installation guide](docs/installation.md) for step-by-step instructions.
3. Open HexaDesktop and sign in with your Hexa account.
4. Follow the [getting started guide](docs/getting-started.md).

## System requirements

| | Minimum | Recommended |
| --- | --- | --- |
| **OS** | Windows 10 (64-bit), macOS 12, Ubuntu 20.04 or equivalent | Latest stable version of your OS |
| **CPU** | 64-bit dual-core | Quad-core or better |
| **Memory** | 4 GB RAM | 8 GB RAM or more |
| **Disk** | 500 MB free | 2 GB free |
| **Network** | Internet connection for sign-in and sync | Broadband |
