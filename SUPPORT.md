# Getting support

1. **Search the docs** — the [FAQ](docs/faq.md) and [Troubleshooting](docs/troubleshooting.md) guides answer most questions.
2. **Search existing issues** — someone may have reported the same problem already: [open issues](https://github.com/gethexa/HexaDesktop-Releases/issues).
3. **Open a new issue**
   - [Bug report](https://github.com/gethexa/HexaDesktop-Releases/issues/new?template=bug_report.yml)
   - [Feature request](https://github.com/gethexa/HexaDesktop-Releases/issues/new?template=feature_request.yml)
4. **Security vulnerabilities** — report them privately as described in [SECURITY.md](SECURITY.md).

When asking for help, always include:

- Your HexaDesktop version (**Help → About HexaDesktop**)
- Your operating system and version
- What you expected to happen, and what happened instead
- Logs, if possible (see [collecting logs](docs/troubleshooting.md#collecting-logs-for-support))
