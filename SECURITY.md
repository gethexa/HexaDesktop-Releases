# Security policy

## Supported versions

Security fixes are provided for the **latest stable release** of HexaDesktop. Please keep automatic updates enabled.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Report them privately using GitHub's [private vulnerability reporting](https://github.com/gethexa/HexaDesktop-Releases/security/advisories/new).

Please include:

- The HexaDesktop version (**Help → About HexaDesktop**) and your operating system
- A description of the issue and its impact
- Steps to reproduce, or a proof of concept

We will acknowledge your report as soon as possible, keep you updated on our progress, and credit you in the release notes if you wish.

## Download safety

- Only download HexaDesktop from the official [Releases page](https://github.com/gethexa/HexaDesktop-Releases/releases).
- Verify every download against `SHA256SUMS.txt` — see [verifying your download](docs/installation.md#verifying-your-download).
- Hexa will never ask for your password by email or chat.
