# Settings reference

Open settings with <kbd>Ctrl</kbd>+<kbd>,</kbd> (<kbd>⌘</kbd>+<kbd>,</kbd> on macOS) or **Account menu → Settings**.

## General

| Setting | Description | Default |
| --- | --- | --- |
| Launch at startup | Start HexaDesktop when you sign in to your computer | Off |
| Minimize to tray | Closing the window keeps the app running in the system tray / menu bar | On |
| Automatic updates | Download and install updates automatically | On |
| Update channel | **Stable** or **Beta** (early access to new features) | Stable |

## Appearance

| Setting | Description | Default |
| --- | --- | --- |
| Theme | Light, Dark or follow the System setting | System |
| Interface zoom | Scale the whole interface | 100% |
| Compact mode | Show more content with less spacing | Off |

## Language

| Setting | Description | Default |
| --- | --- | --- |
| Language | Interface language | Your system language |

## Notifications

| Setting | Description | Default |
| --- | --- | --- |
| Desktop notifications | Show native notifications | On |
| Notification sound | Play a sound with notifications | On |
| Do not disturb | Pause notifications for a period of time | Off |

## Privacy

| Setting | Description | Default |
| --- | --- | --- |
| Usage statistics | Send anonymous usage data to help improve HexaDesktop | On |
| Crash reports | Send crash reports automatically | On |
| Clear local cache | Remove downloaded data from this computer (your account data is not affected) | — |

## Advanced

| Setting | Description | Default |
| --- | --- | --- |
| Hardware acceleration | Use the GPU to render the interface. Turn off if you see display glitches | On |
| Proxy | Use the system proxy or set a custom one | System |
| Open logs folder | Open the folder containing log files for troubleshooting | — |
| Reset all settings | Restore every setting to its default value | — |
