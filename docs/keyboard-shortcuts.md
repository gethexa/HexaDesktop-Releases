# Keyboard shortcuts

On macOS, use <kbd>⌘</kbd> (Command) wherever this table says <kbd>Ctrl</kbd>, and <kbd>⌥</kbd> (Option) instead of <kbd>Alt</kbd>.

## General

| Action | Shortcut |
| --- | --- |
| Command palette / search | <kbd>Ctrl</kbd>+<kbd>K</kbd> |
| Settings | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| New item | <kbd>Ctrl</kbd>+<kbd>N</kbd> |
| New window | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> |
| Close window | <kbd>Ctrl</kbd>+<kbd>W</kbd> |
| Quit | <kbd>Ctrl</kbd>+<kbd>Q</kbd> |
| Show all shortcuts | <kbd>Ctrl</kbd>+<kbd>/</kbd> |

## Navigation

| Action | Shortcut |
| --- | --- |
| Toggle sidebar | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Back | <kbd>Alt</kbd>+<kbd>←</kbd> |
| Forward | <kbd>Alt</kbd>+<kbd>→</kbd> |
| Reload | <kbd>Ctrl</kbd>+<kbd>R</kbd> |

## Editing

| Action | Shortcut |
| --- | --- |
| Undo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |
| Copy / Cut / Paste | <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> |
| Select all | <kbd>Ctrl</kbd>+<kbd>A</kbd> |
| Delete selected | <kbd>Delete</kbd> |

## View

| Action | Shortcut |
| --- | --- |
| Zoom in | <kbd>Ctrl</kbd>+<kbd>+</kbd> |
| Zoom out | <kbd>Ctrl</kbd>+<kbd>-</kbd> |
| Reset zoom | <kbd>Ctrl</kbd>+<kbd>0</kbd> |
| Full screen | <kbd>F11</kbd> (macOS: <kbd>⌃</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd>) |
