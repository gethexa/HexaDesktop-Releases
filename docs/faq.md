# Frequently asked questions

### Is HexaDesktop free?

HexaDesktop is free to download. Features available to you depend on your Hexa account plan.

### Do I need a Hexa account?

Yes. Sign in with the same account you use on the Hexa web app, or create one from the welcome screen.

### What's the difference between HexaDesktop and the Hexa web app?

They share the same account and data. HexaDesktop adds native notifications, keyboard shortcuts, offline mode, launch at startup and automatic updates.

### Which platforms are supported?

Windows 10/11 (64-bit), macOS 12 or later (Apple Silicon and Intel) and 64-bit Linux. See [system requirements](../README.md#system-requirements).

### Where do I download HexaDesktop?

Only from the official [Releases page](https://github.com/gethexa/HexaDesktop-Releases/releases/latest). Don't install HexaDesktop from third-party websites.

### How do I know my download is genuine?

Compare its SHA-256 checksum with the `SHA256SUMS.txt` file published with each release. See [verifying your download](installation.md#verifying-your-download).

### How do I update?

HexaDesktop updates itself automatically. You can also use **Help → Check for updates**. See [updating](installation.md#updating).

### Can I try new features early?

Yes. Switch to the **Beta** channel in **Settings → General → Update channel**. Beta builds are also marked as *Pre-release* on the Releases page.

### Can I install an older version?

Yes, all previous versions are available on the [Releases page](https://github.com/gethexa/HexaDesktop-Releases/releases). Turn off automatic updates first, otherwise the app will update itself again.

### Does HexaDesktop work offline?

Yes. Changes made offline are saved locally and synced when you're back online.

### Is HexaDesktop open source?

No. This repository contains release builds and documentation only.

### How do I report a bug or request a feature?

[Open an issue](https://github.com/gethexa/HexaDesktop-Releases/issues/new/choose) on this repository. For security vulnerabilities, follow the [security policy](../SECURITY.md) instead.
